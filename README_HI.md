# Revision Target — स्थापना मार्गदर्शिका (हिंदी)

## इसमें क्या है?
- मोबाइल-अनुकूल वेबसाइट और नाम + पासकोड लॉगिन
- प्रश्न PDF + उत्तर-कुंजी PDF से AI द्वारा प्रश्न निकालना और नंबर के अनुसार मिलान
- संदिग्ध प्रश्नों/उत्तर को पुष्टि के बाद ही सेव करना
- अध्ययन सामग्री PDF से कठिन MCQ बनवाना
- New Test, Old Topic, क्रमवार अपलोड किए गए टेस्ट
- दैनिक सेक्शन 1 और 2 (प्रत्येक में 100 तक प्रश्न), कम स्कोर वाले टेस्ट के प्रश्नों का पुनरावृत्ति पूल
- रविवार विशेष टेस्ट: पिछले 30 दिनों के उपलब्ध प्रश्न, अधिकतम 200 प्रश्न और 500 अंक
- हर प्रश्न पर 20 सेकंड, अंतिम प्रश्न के बाद स्वतः सबमिट
- UPSC GS जैसी सामान्य टेस्ट मार्किंग: सही +2, गलत −2/3, खाली 0
- रविवार मार्किंग: सही +2.5, गलत −5/6, खाली 0
- परिणाम, प्रतिशत, समय, तारीख, स्टार और रिकॉर्ड
- वेबसाइट खुली होने पर हर 5 मिनट में दैनिक रिमाइंडर

## महत्वपूर्ण सीमाएँ
1. AI से PDF पढ़ने और प्रश्न बनाने के लिए `OPENAI_API_KEY` जरूरी है; API उपयोग पर शुल्क लग सकता है।
2. PDF से टेक्स्ट न निकलने वाली स्कैन/फोटो PDF पर OCR पहले करना होगा। यह संस्करण टेक्स्ट-आधारित PDF पढ़ता है।
3. प्रश्न बैंक में सही उत्तर वाली प्रविष्टियाँ ही टेस्ट में आती हैं। संदिग्ध उत्तर को अपलोड स्क्रीन पर ठीक करके सेव करें।
4. दैनिक टेस्ट में 100-100 प्रश्न तभी मिलेंगे जब प्रश्न बैंक में पर्याप्त प्रश्न हों। सिस्टम प्रश्न गढ़कर संख्या पूरी नहीं करता। रविवार टेस्ट भी उपलब्ध पिछले 30 दिनों के प्रश्नों तक सीमित है।
5. वेबसाइट हर 5 मिनट रिमाइंडर तभी दिखाती है जब साइट खुली हो। टैब/ब्राउज़र बंद होने पर संदेश नहीं आएगा।
6. साझा पासकोड + नाम से अलग रिकॉर्ड बनते हैं, लेकिन यह मजबूत व्यक्तिगत पहचान नहीं है: कोई दूसरा व्यक्ति वही नाम डालकर रिकॉर्ड देख/बना सकता है। वास्तविक अलग-अलग उपयोगकर्ता सुरक्षा के लिए बाद में अलग अकाउंट/पासवर्ड जोड़ना चाहिए।
7. वेबसाइट का डेटा सुरक्षित रखने के लिए persistent disk/database वाली hosting जरूरी है। केवल ephemeral/free hosting पर SQLite फाइल रीस्टार्ट/रीडिप्लॉय होने पर मिट सकती है।
8. यह परियोजना आपके सर्वर पर डेटा रखती है। सार्वजनिक रूप से साझा करने से पहले पासकोड और API key को केवल hosting के Environment/Secrets में रखें।

## अपने कंप्यूटर पर चलाना
Node.js 20+ इंस्टॉल करें। इस फ़ोल्डर में terminal खोलकर:
1. `npm install`
2. `.env.example` की कॉपी बनाकर `.env` नाम दें।
3. `.env` में:
   - `PASSCODE` में अपना पासकोड लिखें
   - `JWT_SECRET` में लंबा, अनोखा random secret लिखें
   - `OPENAI_API_KEY` में अपनी API key लिखें
4. `npm start`
5. ब्राउज़र में `http://localhost:3000` खोलें।

## ऑनलाइन प्रकाशित करना (Render)
यह प्रोजेक्ट `render.yaml` के साथ है।
1. इस ZIP को खोलकर प्रोजेक्ट को अपने निजी GitHub repository में अपलोड करें।
2. Render पर नया Blueprint/Web Service बनाकर उस repository को जोड़ें।
3. Environment variables में `PASSCODE` में आपका चुना हुआ पासकोड और `OPENAI_API_KEY` में API key भरें।
4. `JWT_SECRET` को Render पर generated/लंबे random secret के रूप में रखें।
5. Persistent disk `/var/data` जुड़ी होनी चाहिए; `DATA_DIR=/var/data`, `UPLOAD_DIR=/var/data/uploads` सेट हों।
6. Deploy पूरा होने पर Render जो वेबसाइट लिंक दे, उसे मोबाइल में खोलें।

Render पर persistent disk वाले प्लान का शुल्क लग सकता है। केवल मुफ्त प्लान का चयन करने पर स्थायी रिकॉर्ड की गारंटी नहीं होती। Hosting provider की वर्तमान कीमत/शर्तें अलग से जाँचें।

## प्रश्न अपलोड करने का तरीका
- अगर प्रश्न पेपर और उत्तर-कुंजी अलग PDF हैं: `PDF अपलोड` → दोनों फाइल चुनें → मिलान करें → संदिग्ध प्रश्नों के उत्तर की जाँच करें → पुष्टि किए गए प्रश्न सेव करें।
- अगर आपके पास अध्याय/नोट्स की PDF है: अध्ययन सामग्री PDF चुनें → AI से प्रश्न बनाएँ।
- बेहतर नतीजों के लिए स्पष्ट, searchable text PDF अपलोड करें। उत्तर-कुंजी में प्रश्न नंबर और A/B/C/D स्पष्ट होने चाहिए।

## स्कोर और स्टार
- 98% से अधिक: 5 स्टार, Best
- 90% से 98% तक: 4 स्टार, Very Good (आपके मूल नियम में 90–97% लिखा था; 98% को भी 4 स्टार रखा गया है क्योंकि 5 स्टार केवल 98% से अधिक पर हैं)
- 90% से कम: 3 स्टार और Bad
- दैनिक पॉइंट: दोनों दैनिक सेक्शन पूरे करने पर दिन का 1 पॉइंट। हर 7 पॉइंट पर स्तर बढ़ता है, अधिकतम स्तर 5।

## अगली आवश्यक सुधार-सूची
- अलग-अलग उपयोगकर्ताओं के लिए ईमेल/पासवर्ड या admin accounts
- OCR आधारित स्कैन PDF पढ़ना
- प्रश्नों के लिए संपादन/डिलीट और duplicate detection
- सर्वर-स्तर पर हर प्रश्न का timer सत्यापन (अभी timer ब्राउज़र में चलता है; अत्यधिक तकनीकी उपयोगकर्ता इसे बदल सकता है)
- backup/export सुविधा
